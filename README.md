# Credit_fraud_detection_project

*Developed a machine learning–based system to identify fraudulent credit card transactions.

*Performed data preprocessing, feature scaling, and handling of imbalanced datasets.

*Trained and evaluated classification models achieving high prediction accuracy.

*Built a user-friendly GUI using Tkinter for real-time fraud prediction.

*Technologies:
Python, Pandas, NumPy, Scikit-learn, Machine Learning, Tkinter
